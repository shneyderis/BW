# Beykush Winery Dashboard

Статичний дашборд виноробні: фінанси, продажі, товари, склад, маркетинг, партнери, ЗП, виробництво.
Дані — Google Sheets + CSV з 1С/InnoVint. Хостинг — Vercel: https://project-33ms4.vercel.app

- **STATUS.md** — де ми зараз, що очікує від власника, план, журнал змін (видно й у вкладці 📋 Статус).
- **DOCS.md** — як влаштовано, джерела даних, як їх оновлювати, схеми листів.
- **CLAUDE.md** — інструкції та індекс функціоналу для Claude (щоб не робити двічі те, що вже є).
- `tools/` — конвертація 1С, знімок таблиць, аналіз даних → `reports/latest.md`.
- `tests/` — синтетичні дані + smoke-тест: `python3 tests/make_fixtures.py && node tests/smoke.js`.
